description: Review existing translations for problems a validator cannot see
---

Review this project's existing translations.

Use the `review-translations` prompt the StringLane MCP server provides. It
already describes what to look for and how to report it.

Do **not** restate the plan → validate → apply workflow here. It is described in
`/stringlane:translate` and in the server's own instructions, and a second copy
is the one that nobody updates when the first changes.

What this command is for is the class of problem validation cannot reach: a
translation that is correct and wrong — right words, wrong register; a brand name
that got translated; a string that fits in English and overflows the button in
German. Report them; change nothing without asking.
